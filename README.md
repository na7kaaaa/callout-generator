# callout-generator

Notion埋め込み用の、色を自由にカスタマイズできるコールアウト（吹き出し）ジェネレーターです。
背景色・文字色・枠線色をHEXで指定して、プレビューを見ながら埋め込み用のHTMLコードを生成できます。

## できること

- 背景色・文字色・枠線色をカラーピッカー or HEX直打ちで指定
- 枠線のON/OFF・太さ・角丸・余白をスライダーで調整
- アイコン（絵文字）・見出し・本文を自由に編集してリアルタイムプレビュー
- ワンクリックで埋め込み用HTMLコードをコピー

## 使い方

1. 色・文言・スタイルを調整してプレビューを確認
2. 「コピー」ボタンで生成されたHTMLコードをコピー
3. コピーしたコードを `index.html` として保存し、別リポジトリ or 同リポジトリの `/dist` などで公開
4. 公開されたURLを、Notionの **`/埋め込み`（Embed）** ブロックに貼り付け

## GitHub Pagesでの公開手順

1. このリポジトリの Settings → Pages を開く
2. Source を `main` ブランチ（該当フォルダ）に設定
3. 発行されたURLにアクセスして動作確認
4. そのURLをNotionの埋め込みブロックに貼れば完成

## ファイル構成

```
.
└── index.html   # ジェネレーター本体（このリポジトリのメインファイル）
```
